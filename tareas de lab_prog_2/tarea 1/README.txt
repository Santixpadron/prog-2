Sistema de Gestión Hospitalaria en C++

Se ha implementado un sistema integral de gestión hospitalaria utilizando exclusivamente estructuras fundamentales de C++, punteros y arreglos dinámicos, sin emplear componentes STL. La arquitectura modular abarca tres componentes principales: gestión de pacientes, administración médica y coordinación de citas, todos operando en memoria con control estricto de recursos.

Cada módulo gestiona registros completos con validaciones robustas y mantiene relaciones dinámicas entre entidades. El sistema emplea funciones especializadas para redimensionamiento automático de arreglos y validación de datos, mientras garantiza la integridad referencial mediante identificadores únicos.

La estructura central consolida todos los componentes mediante arreglos dinámicos con gestión automática de memoria, previniendo fugas mediante protocolos de liberación en terminación. La interfaz presenta menús jerárquicos con formato profesional, constituyendo un ejercicio completo de programación estructurada que demuestra dominio del manejo manual de memoria en C++.
